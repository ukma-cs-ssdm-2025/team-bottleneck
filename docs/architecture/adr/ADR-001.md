# ADR-001: Архітектура для системи паркування

**Статус:** Прийнято  
**Дата:** 2025-09-28  

## Контекст
- **FR-001**: відображення вільних паркомісць на карті.  
- **FR-002**: інтеграція з платіжними сервісами.  
- **NFR-001**: час відображення списку ≤ 3 сек.  
- **NFR-004**: адаптивний інтерфейс.

## Наслідки
- ✅ Масштабування окремо для фронтенду й бекенду (можна додати підтримку мобільного додатку або розширити бази даних без кардинальних змін).  
- ✅ Просте розширення функціоналу (нові сервіси).  
- ⚠️ Потрібен балансувальник навантаження при високому трафіку.  
- ❌ Додаткова затримка через мережу (але в межах NFR-001).  

## Розглянуті альтернативи
- **Моноліт** — відхилено (важко масштабувати).  
- **Serverless** — відхилено (складність інтеграції з платіжними сервісами).
