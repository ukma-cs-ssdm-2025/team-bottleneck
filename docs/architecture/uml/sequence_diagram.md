# Діаграма послідовності (Sequence Diagram)

## Опис

Діаграма послідовності демонструє процес онлайн-оплати паркінгу від пошуку вільного місця до підтвердження платежу.

## Учасники

- **Driver (User)** - водій/користувач системи
- **ReactUI** - клієнтський інтерфейс
- **REST API** - RESTful API сервер
- **Python App (Бізнес-логіка)** - серверний застосунок
- **DAO** - Data Access Object
- **PostgreSQL** - база даних
- **Платіжна система** - зовнішній платіжний сервіс

## Сценарій використання

### 1. Пошук доступних місць
- Користувач відкриває карту паркінгу
- ReactUI запитує доступність через REST API
- Python App виконує SQL-запит через DAO
- База даних повертає список вільних місць
- Дані відображаються на карті

### 2. Вибір місця
- Користувач обирає вільне місце
- ReactUI запитує розрахунок вартості
- Python App отримує ціну з бази даних
- Вартість відображається користувачу

### 3. Оплата
- Користувач підтверджує оплату
- Python App відправляє запит до платіжної системи
- Платіжна система обробляє платіж
- Транзакція зберігається в базі даних
- Користувач отримує підтвердження оплати

## Основні операції

- `SELECT * FROM ParkingLots` - отримання доступних місць
- `SELECT price FROM ParkingLots WHERE id=...` - отримання ціни
- `INSERT INTO Transactions` - збереження транзакції
- API-запит до платіжної системи для обробки оплати
